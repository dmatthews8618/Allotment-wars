# Painted building art

All sixteen faction-specific building sprites now use an AI-generated, painterly atlas. Image generation supplied the building forms, material textures and lighting; a second image-tool pass refined the asset. Runtime canvas compositing extracts and scales each sprite into the existing building footprint and produces matching sidebar icons.

Plot Holders have a weathered blue shed with porch, glazed planting greenhouse, timber rain barrel, black compost bins with a barrow, translucent polytunnel, straw scarecrow, wooden hive and brass sprinkler tripod. Tidy Lawns have a brick clubhouse, gnome workshop, irrigation pump, wheelie bins, mower garage, topiary turret, wasp nest and mechanical hose turret.

The original unit statistics, building dimensions and costs are retained. Art stays inside the original footprint so placement previews, collision, selection corners and health bars still agree. All sprite textures are produced at the existing 2× resolution, use consistent alpha cutouts and work with existing construction, damage and destruction effects.

## Asset pipeline

- `assets/buildings.webp`: production artwork, approximately 617 KiB, converted from the image tool's transparent master with ImageMagick.
- `src/building-atlas-data.js`: generated by `python3 tools/build.py`; embeds the WebP as a data URL to support direct-file opening and the single-file version.
- `src/building-art.js`: measured atlas rectangles, one-time transparent-margin analysis, aspect-preserving scaling and procedural fallback.
- `Main.preload()`: decodes the image once before building textures are created; replays reuse the atlas.

Do not format the generated data script. Make changes to the artwork or frame manifest, then rebuild. The generated image masters remain in the workspace's `generated_images/` directory. The source reference for the current atlas is `exec-508a4494-1014-4eed-9362-cf60388837e3.png`.

`../screens/buildings-before.png` and `../screens/buildings-after.png` show both factions at normal size and 1.65× enlargement. Battlefield captures in `screens/` are the final check for how the buildings sit against terrain and fog. These screenshots are local review artifacts, intentionally excluded from Git.
